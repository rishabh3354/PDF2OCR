PDF2OCR — Extract Text from Scanned PDFs & Images (Linux OCR)

Turn scanned PDFs, photographed pages and screenshots into editable text with Tesseract OCR. Recognise whole documents at once, straighten tilted scans and phone photos, copy tables into a spreadsheet, and export to searchable PDF, Word or Excel. Everything runs offline on your own computer. Open source under the MIT licence.

Snap Store GitHub

Download and install PDF2OCR

Linux — Snap

sudo snap install pdf2go

Using a USB scanner? Allow access once with sudo snap connect pdf2go:raw-usb.

Run from source

sudo apt install python3-pyqt5 tesseract-ocr poppler-utils sane-utils
git clone https://github.com/rishabh3354/PDF2OCR.git
cd PDF2OCR
pip install -r requirements.txt
python3 src/pdf2go.py

From the terminal

pdf2go --to pdf ~/Scans                      # searchable PDFs, no window needed
pdf2go --to txt --lang deu+eng -o out/ *.pdf # text files
pdf2go --to xlsx statements/                 # tables to Excel
pdf2go --capture                             # screen area to clipboard

The application is MIT licensed — see the repository.

Features

Whole documents at once

Every page is recognised, several in parallel, with progress and a Stop button.

Your languages

15 built in, 100+ more one click away. German and English in one letter? Pick both.

Exact text from digital PDFs

Real PDF text is copied as-is; OCR is only used for scanned pages.

Straightens pages

Sideways, upside-down and tilted scans are corrected automatically before reading.

Phone photos

Fix perspective: the page corners are found and the photo is flattened into a proper page.

Screenshots & quick capture

Paste with Ctrl+V, capture a screen area, or press a shortcut anywhere to copy text.

Scan directly

USB and network scanners, flatbed page by page or the whole document feeder.

Select an area

Read just part of a page, or copy a table and paste it into a spreadsheet as cells.

Check with confidence

Text and page are linked word by word; uncertain words are flagged in both.

Find & replace

Across all pages, with undo. Your work is saved automatically and survives a crash.

Export your way

Searchable PDF, Word, LibreOffice, Markdown, plain text, Excel and CSV.

Private and offline

Nothing is uploaded, and the text is never translated or rewritten. MIT licensed.

Frequently asked questions

Is PDF2OCR free?

Yes. It is free to install from the Snap Store, and the source is MIT licensed.

Does it send my documents anywhere?

No. OCR runs locally with Tesseract on your own machine and works without an internet connection. The network is only used if you open a file from a URL or download an additional OCR language.

What file types can it read?

PDF files, including scanned and multi-page PDFs, plus JPG, JPEG, PNG, BMP, TIFF (multi-page too), GIF and WebP images. It can also take screenshots from the clipboard or the screen, and scan directly from USB and network scanners.

Which languages does it recognise?

15 languages are included, among them English, German, French, Spanish, Italian, Portuguese, Dutch, Polish, Russian, Ukrainian, Turkish, Arabic, Hindi, Chinese and Japanese. More than 100 others can be downloaded inside the app. Pick every language in your document for the best results.

Is there a page limit?

No. It handles documents with any number of pages and recognises several pages in parallel.

How accurate is the OCR?

It uses Tesseract, so accuracy depends on the source. Clean 300 DPI scans read very well. PDF2OCR straightens tilted pages and phone photos, keeps the exact text of digital PDFs, and flags words it is unsure about so you know what to check. Heavy blur, tiny print and handwriting remain hard.

What can I export to?

Searchable PDF, Word (.docx), LibreOffice (.odt), Markdown, plain text, and Excel (.xlsx) or CSV for tables. You can also copy all text, or copy a table straight into a spreadsheet.

Does it translate or change the text?

No. Earlier versions offered translation, which could silently change the recognised text. PDF2OCR now gives you exactly what the OCR engine read.

Can I use it from the command line?

Yes. For example, pdf2go --to pdf ~/Scans turns a folder of scans into searchable PDFs without opening a window, and pdf2go --capture copies the text of a screen area to the clipboard.

Why is the snap called pdf2go?

The application shipped under the name PDF2Go before it was renamed, and the snap name cannot be changed without losing existing installs. snap install pdf2go is correct.

Is it available for Windows or macOS?

Not currently. The packaged build is Linux only. The source is Python and PyQt5, so it may run elsewhere, but that is untested.
